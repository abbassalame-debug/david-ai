# Tolerances (Job 1: restaurant operations, Demo Bistro)

SYNTHETIC example. Set by the demo manager; working rules to be revisited.

## Meat weights
- The scale is not exact: a difference under 0.5 kg per meat per day is normal and is only noted.
- A difference above 1.5 kg is a CHECK for the manager.

## Cash
- A cash difference under 1.00 USD is normal and is only noted.
- Above 5.00 USD is a CHECK for the manager.
