# templates/

Registered Illustrator templates go here (`<template_id>.ai`). They are git-ignored and not included in this repository.
`agents/jobs/02_brand_marketing/reference/templates.json` lists the registered ids, the text field each one fills, and the SHA-256 of the file it was inspected from
(zeros in the demo registry; the tests skip the "real file present" checks when the file is absent).
